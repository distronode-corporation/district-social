# Support

district-social is a small open source project maintained by Distronode Corporation, with
no paid support and no service-level commitment.

- **Questions and bugs:** open an issue with the bug report or feature request form at
  <https://github.com/distronode-corporation/district-social/issues/new/choose>.
- **Security vulnerabilities:** report them privately, never in an issue. See
  [SECURITY.md](SECURITY.md).
- **Contributing:** [CONTRIBUTING.md](CONTRIBUTING.md) has the local gate and the rules.

Only the latest release on npm is supported. The project does not provide credentials,
developer apps or network approvals for anyone's deployment, and cannot help with a social
network's own API, account or review process; ask that network.
